# Netflix UI Clone

A Flutter-based learning project inspired by the Netflix mobile interface.

This project was created to practice building mobile interfaces with Flutter, working with reusable widgets, layouts, assets, and navigation.

> **Project Note**
>
> This is an older learning project and is preserved as part of my mobile development journey.
>
> It is an unofficial UI clone created for educational purposes and is not affiliated with Netflix.

## About

The project recreates parts of the Netflix-style mobile experience using Flutter and Dart.

The goal of the project was to practice translating an existing product design into a mobile application while learning Flutter UI development.

## Tech Stack

- Flutter
- Dart
- Material Design
- Asset-based images
- Android
- iOS

## Running the Project

Make sure Flutter is installed on your machine.

Clone the repository:

```bash
git clone https://github.com/himanshu240601/netflix-clone.git
cd netflix-clone
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
